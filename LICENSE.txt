1. What this software is
   QAX Loop is an in-house Reach Subsea application that drives the open-source
   AusSeabed QAX grid checks and the GGOutlier depth-spike detector, and adds
   cross-run failure tracking, a review workflow and client-ready PDF/XLSX
   reports.  It installs a self-contained copy of Python and the libraries it
   needs, so nothing else has to be installed on this computer.
