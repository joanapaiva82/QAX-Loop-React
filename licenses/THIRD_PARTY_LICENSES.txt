QAX Loop -- Third-party components and their licenses
=====================================================

QAX Loop bundles a private Python runtime and the open-source libraries it
depends on.  Each library's own full licence text travels inside the bundle in
its metadata folder (app\python\Lib\site-packages\<name>-<version>.dist-info\).
This file is a summary; where a full text is required it is included alongside
(see Apache-2.0.txt) or found in the dist-info folder noted above.

Notes
-----
- PySide6 / shiboken6 / ausseabed.qajson are LGPL-3.0 and are shipped as
  loose, dynamically-loaded files (not statically linked); see
  PySide6-LGPL-NOTICE.txt for the source-availability statement that satisfies
  the LGPL for all three.
- PyMuPDF (AGPL-3.0) is NOT included: it is not used by the application and is
  removed from the bundle during the build.
- The two AusSeabed engines whose metadata does not declare a SPDX id are
  open-source projects of AusSeabed / NOAA OCS / UNH CCOM-JHC
  (https://github.com/ausseabed); their repositories carry the authoritative
  licence.
